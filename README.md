# E-Commerce Customer Segmentation & Revenue Analytics

An end-to-end customer analytics project using Python, RFM analysis, K-Means clustering, and an interactive dashboard.

## Live Dashboard

The interactive dashboard analyzes customer behavior, revenue, products, markets, and returns.

## Business Problem

How can an online retailer identify high-value customers, understand purchasing behavior, and develop targeted retention strategies?

## Objectives

- Analyze e-commerce transaction data
- Clean and prepare the dataset
- Perform exploratory data analysis
- Calculate RFM metrics
- Segment customers using K-Means clustering
- Identify high-value and at-risk customers
- Analyze product and country performance
- Develop customer retention strategies

## Key Results

- £8.28M Net Revenue
- £8.89M Gross Sales
- £608.69K Returns
- 6.85% Return Rate by Value
- 4,371 Customers
- 22,186 Orders
- 3,684 Products
- 37 Countries
- 5 Customer Segments

## Key Finding

Champions represented only 10.27% of customers but generated 57.38% of total revenue, highlighting significant revenue concentration and the importance of VIP customer retention.
